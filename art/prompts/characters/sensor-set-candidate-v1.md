# Sensor set candidate v1 prompt

Use case: illustration-story  
Asset type: children's-book canonical character-set reference candidate  
Input images: the four sensor prototype images in `art/concepts/prototype-references/` - concept and function cues only, not edit targets  

## Prompt

Create one polished children's-book character reference sheet containing exactly four small sensor companions in a visually coherent family. Preserve the color and instrument cues of the supplied prototypes while resolving all four into one consistent original design language.

1. Scout is teal, alert and curious, looking through clearly recognizable binoculars.
2. Meter is warm amber and careful, holding a clearly recognizable measurement gauge with a needle and scale.
3. Check is blue and methodical, carrying a clipboard with simple check boxes but no readable words.
4. Proof is green and confident but friendly, presenting one large green check mark as a summary of evidence.

Each companion has a distinct silhouette and exactly one instrument. They verify facts; they do not repair, command or decide. Proof's check mark must look like a check mark and never like a key.

Composition: four equal full-body figures in a single horizontal row, same scale and baseline, generous separation, plus one small neutral expression study beneath each figure. Do not merge the characters.

Style: same premium hand-painted children's-book watercolor and gouache style intended for Oki and Aia, gentle linework, readable at small book size, warm and timeless rather than glossy 3D animation.

Backdrop: clean warm off-white paper, no environment and no cast shadows.

Constraints: exactly four characters; no text, labels, names, logo or watermark; no key, gate, town hall, island, egg, repair tools or weapons; no fifth character; no duplicated instrument; complete silhouettes with generous padding.
