# Art production

## Status flow

`CONCEPT -> CANDIDATE -> CANONICAL -> RETIRED`

`CANONICAL` requires:

- Character and architecture conformance `PASS`
- rights review `PASS`
- source and prompt integrity
- complete provenance
- explicit human approval

## Directories

- `concepts/` - exploration, never publication truth
- `canonical/` - approved source assets
- `keyframes/` - four acceptance frames after character approval
- `scenes/` - final scene art
- `prompts/` - versioned creative briefs and prompts
- `provenance/` - one record per candidate or final asset

Large source assets belong in Git LFS or an explicitly referenced artifact store.
