# Canonical symbols

The meaning of a recurring symbol is stable across book, technical guide, slides and video.

- `cluster-egg/` - a declared cluster that may be emerging; not yet ready
- `town-hall/` - Kubernetes control plane, one per independent cluster
- `lighthouse/` - observability, not automatic repair
- `contract-book/` - stable capabilities and guarantees
- `gate-and-key/` - controlled change and human authority

Detailed rules are normative in the Canon.
