# Conductor character assets

Conductor is the active personification of Crossplane Composition for the Aia
Illustrated Guide.

- **Identity:** the friendly orange beaver evolved from the earlier Cops concept
- **Role:** conducts approved Compositions and their resources through continuous reconciliation
- **Visual language:** deep teal conductor tailcoat, copper piping, baton and Composition score
- **Boundary:** approves nothing, holds no Authority key and does not imply imperative workflow control
- **Status:** `CONCEPT`

The earlier `aia/characters/cops/` asset remains only as historical concept
lineage.
