# Gate 2B - Character references

**Status:** APPROVED / CLOSED  
**Opened:** 2026-08-08 after Gate 2A approval
**Closed:** 2026-08-08 by human project owner

## Scope

Produce and review candidate reference sheets for:

- `OKI-CHAR-001-v1`
- `AIA-CHAR-001-v1`
- `OKI-SENSOR-SET-001-v1`

This gate decides how the recurring characters look. It does not approve scene composition and does not authorize the four acceptance keyframes.

## Candidate requirements

- [x] full silhouette is readable at small book size
- [x] canonical colors and personality are recognizable
- [x] front, three-quarter, side and required expression views are consistent
- [x] Oki does not resemble a Pod, VM or product mascot
- [x] Aia has no authority key and no autonomous-decision symbolism
- [x] each sensor has one unambiguous instrument and function
- [x] no cluster, VM or Pod identity is accidentally encoded in a character
- [x] prompts, sources, model/tool and generation identifiers are recorded
- [x] source and prompt hashes are recorded
- [x] conformance result is `PASS`
- [x] rights review is `PASS`
- [x] human approval is recorded
